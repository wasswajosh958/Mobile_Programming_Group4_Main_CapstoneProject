CBC Teachers' Toolkit - Group 4 Project

This is an Android application we built for our Capstone project at Ndejje University. The app is called CBC Teachers' Toolkit and it helps secondary school teachers get teaching materials easily.

What the app does
We made this app to help teachers who might not have internet all the time.
- It has offline materials like PDFs and Videos for different subjects.
- Teachers can save their favorite topics so they find them fast later.
- There is a Library section where all saved materials are kept.
- We also added a tool for teachers to make Schemes of Work right in the app.
- It has a splash screen and looks nice on the phone.

How we built it
We used the latest Android stuff to make sure it works well:
- Kotlin and Jetpack Compose: For building the screens and the UI
- MVVM: This is how we organized the code so it's not messy
- oom Database: This is what we used to save favorites and notes on the phone
- Navigation: To move between the different screens like Home, Library and Details

Our Screens
1. Splash Screen: The first screen you see when the app opens.
2. Home Screen: Shows different subjects and quick links.
3. Subjects Screen: Lists all the topics for a subject.
4. Library: Where you find your bookmarked stuff.
5. Detail Screen: Shows the actual content like lesson plans and buttons to open PDFs.
6. Scheme Builder: A form to help teachers plan their work.

Testing
We wrote some tests to make sure the favorites work and the navigation doesn't break
